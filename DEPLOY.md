# Plesk Deployment Guide

## How it works

- `npm run build` compiles the React frontend into `dist/assets/` and bundles
  the Express server into `dist/server.cjs`.
- In production, the Express server serves the static `dist/` files and handles
  all `/api/*` routes. Every other URL (including `/admin`) falls through to
  `dist/index.html` and React Router takes over client-side.
- `data/db.json` is the database. It lives in the project root and is never
  inside `dist/`. Keep it on the server — it persists between deployments.

---

## What to upload to Plesk

Upload the entire project folder **after running `npm run build`** locally.
The minimum required files on the server are:

```
dist/               ← compiled frontend + server (generated by build)
data/db.json        ← database (keep this, never overwrite with a blank one)
package.json        ← needed for npm install
package-lock.json   ← needed for npm ci
node_modules/       ← OR run `npm ci --omit=dev` on the server instead
```

> Tip: run `npm ci --omit=dev` on the server to install only production
> dependencies and skip devDependencies (esbuild, tsx, typescript, etc.).

---

## Plesk Node.js App Setup

1. In Plesk, go to **Domains → your domain → Node.js**.
2. Set **Node.js version** to 18 or higher.
3. Set **Application root** to the folder you uploaded (e.g. `/httpdocs`).
4. Set **Application startup file** to `dist/server.cjs`.
5. Set **Environment variables**:
   - `NODE_ENV` = `production`
   - `PORT` = whatever port Plesk assigns (usually set automatically via Passenger)
6. Click **Enable Node.js** and then **Restart**.

---

## Running manually (SSH)

```bash
# From the project root on the server:
npm ci --omit=dev
NODE_ENV=production node dist/server.cjs
```

Or with a specific port:
```bash
PORT=8080 NODE_ENV=production node dist/server.cjs
```

---

## Deployment workflow (updating the site)

```bash
# On your local machine:
npm run build

# Upload / rsync the dist/ folder to the server
# (data/db.json should NOT be overwritten — it has live data)

# Restart the Node.js app in Plesk (or via SSH: kill the old process and start again)
```

## Routes

| URL | Handled by |
|-----|-----------|
| `/` | React SPA (served from `dist/index.html`) |
| `/admin` | React SPA (same `index.html`, React handles the route) |
| `/api/*` | Express API routes (read/write `data/db.json`) |
| `/api/db/download` | Downloads `db.json` as a file |
